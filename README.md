# Video Analytics

カメラの映像からリアルタイムで物体検出（人物検出）と、その人物のアクション（動作）分析を同時に行うアプリケーションです。

## 使用しているモデルと性能

本システムでは、以下の2つのモデルを組み合わせて機能を実現しています。

### 1. 物体検出モデル (Object Detection)
*   **使用モデル:** YOLOv8 (デフォルト: `yolov8n.pt`)
*   **役割:** カメラ映像からリアルタイムで対象物（デフォルト設定では「人物」のみ）を検出・トラッキングします。
*   **性能:** YOLOv8 nanoモデルを採用しているため非常に軽量です。CPU処理でも高速に動作し、映像のフレームレート（FPS）を高く保ちながらリアルタイム描画を行うことが可能です。

### 2. 視覚言語モデル (VLM: Vision-Language Model)
*   **使用モデル:** Qwen2-VL (`Qwen/Qwen2-VL-2B-Instruct` / `Qwen/Qwen2.5-VL-3B-Instruct`)
*   **役割:** YOLOが推論している映像をバックグラウンドで解析し、「画像内の人物が何をしているか？」(Action) を短い文章で出力します。
*   **性能:** 18億(1.8B)パラメータを持つ比較的小型のVLMですが、高性能な分析が可能です。ただし、推論には重い計算処理が必要となるため、映像のFPSを低下させないよう、この処理は独立したスレッドで非同期に実行させています。

## 動作に必要なスペック (推奨要件)

VLM(Qwen2-VL)の実行を含むため、ある程度のハードウェアスペックが求められます。

*   **OS:** Linux (※Windows WSL2環境で実行する場合は、カメラデバイスのパススルー設定 `usbipd-win` などが別途必要です)
*   **メモリ (RAM):** 8GB 以上必須 (16GB以上を推奨)
*   **GPU (推奨):**
    *   CPUのみでも動作しますが、VLMの回答に数秒〜数十秒の遅延が発生します。
    *   **NVIDIA GPU (VRAM 4GB以上、推奨6GB以上)** を使用することで、VLMの推論速度が大幅に向上し、より快適な分析結果を得ることができます。
*   **カメラ:** 標準的なWebカメラ (OpenCVの `cv2.VideoCapture` で認識できるデバイス)

## 実行方法

### 1. 初期セットアップとパッケージのインストール

仮想環境を使用するかどうかによって手順が変わります。いずれの場合も、まずはプロジェクトのディレクトリに移動してください。

#### Linux環境をご利用の場合 (WSL2含む)
GUIシステム (Tkinter) を動作させるため、OS側に `python3-tk` パッケージのインストールが必要です。
※このインストールは仮想環境を作るたびに実行する必要はなく、お使いのPC(OS)において初回1度だけ行えばOKです。

```bash
sudo apt update
sudo apt install -y python3-tk
```

#### パターンA: 仮想環境を新しく作成して実行する場合（推奨）
プロジェクトディレクトリ内で仮想環境を作成・有効化し、パッケージをインストールします。

```bash
# 1. 仮想環境の作成 (※初回のみ)
python -m venv venv

# 2. 仮想環境のアクティベート
# Linux / macOS の場合:
source venv/bin/activate
# Windows の場合:
# venv\Scripts\activate

# 3. 必要なパッケージのインストール (※初回のみ)
pip install -u pip
pip install -r requirements.txt
```

#### パターンB: 既存の環境にそのままインストールする場合
仮想環境を使用せずにグローバル環境などで実行する場合は、以下のコマンドで直接パッケージをインストールします。

```bash
pip install -r requirements.txt
```

### 2. アプリケーションの起動

パッケージのインストールが完了したら、以下のコマンドでシステムを起動します。（仮想環境を作成した場合は、アクティベートした状態で実行してください）

```bash
python main.py
```

*   **終了方法:** アプリケーションのウィンドウ（映像用画面）上でキーボードの `q` を押すと終了します。
